# AIOU Study Planner

A simple planner that turns a list of your current AIOU courses into one merged day-by-day study schedule.

## What the Project Does

AIOU Study Planner is a single-page web app for AIOU students who are self-studying multiple courses at once. You enter each course you're currently taking (name, content type, days left until the exam or deadline, and your current level), along with how many hours you have free per day. The app then builds one combined daily schedule that spreads your available time across all your courses — instead of you manually figuring out how to split limited study hours between five different subjects with different deadlines.

## Why I Built It

As an AIOU student, I juggle several courses at once with no fixed class schedule, self-studying from course handouts. A generic "study planner" that only handles one course at a time doesn't reflect how AIOU distance learning actually works — the real problem is deciding how to split a limited daily time budget across multiple courses with different urgency levels. I built this to solve that specific problem for myself, and as a project to demonstrate how I used Claude as a development partner while learning to build software.

## Key Features

- Add multiple courses with: course name, content type (theoretical / numerical / conceptual / mixed), days remaining until exam/deadline, and self-rated level (beginner / intermediate / advanced)
- Set a single daily hours budget that gets split across all active courses
- Generates a merged day-by-day study plan, with topics sequenced for recognized AIOU BSCS courses (e.g. Data Structures, Databases, Theory of Automata, Calculus, ANN/Machine Learning, Parallel & Distributed Computing, IT Service Management, Java/OOP) — courses it doesn't recognize fall back to a generic study-phase template
- Each day's tasks include a short explanation of how to approach that topic and a set of revision questions
- A "Get a self-check prompt" button on each task, offering recall/teach-back style self-testing prompts
- Checkboxes to mark tasks done, with a live progress bar
- Runs as a single HTML file — no installation, no backend, no account, no internet connection required after the page loads

## How I Built It / Technologies Used

- Plain HTML, CSS, and vanilla JavaScript — no frameworks, no build tools
- Everything (topic sequences, explanation templates, question templates) is generated by JavaScript logic running entirely in the browser
- No backend server and no external API calls — the app is fully self-contained in one `.html` file

## How Claude Helped Me During Development

I used Claude (through the Claude.ai chat interface, not the API) as a development partner throughout this project — from identifying the problem to worth solving, to scoping what an achievable first version would look like, to writing and iteratively debugging the HTML/CSS/JavaScript. I went through a real build process with Claude: an early version attempted to call the Claude API live from the browser, which caused errors (including a real bug from unsafely embedding data inside an HTML attribute); we debugged that together and I chose to rebuild the app as a fully local, offline version instead — this README reflects that final version. The project code itself does not call any Claude/Anthropic API.

## How to Run It Locally

No installation needed.

1. Download or clone this repository
2. Find the file `aiou-study-planner.html`
3. Double-click it (or right-click → Open with → your browser)
4. It opens directly in your browser and works immediately — no server, no dependencies, no setup
